Methodology

Performance Calculation

  • Stocks: Weighted by reported market value. Daily returns from price changes.
  • Options: Premium calculated via Black-Scholes using your strike/expiry/IV inputs. Daily option prices simulated using BS with time decay.
  • Weighting: Stocks weighted by value; options weighted by calculated premium (not notional).
  • AUM Changes: New capital doesn't affect returns—each quarter uses percentage weights.

Limitations: 13Fs exclude shorts, non-US holdings, small positions. Option parameters are estimates. Actual performance will differ.
